# Indice del package Analysis
- `/attribute`: Classi per l'analisi a livello di singolo attributo.
- `/cluster`: Logiche per l'analisi, metriche e manipolazione dei cluster.
- `/difference`: Utilità per calcolare e analizzare le differenze tra set di dati.
- `/record`: Strumenti di analisi applicati ai record interi.
- `/results`: Classi e oggetti per la memorizzazione dei risultati dell'analisi.
- `/utils`: Classi di utilità generiche per le operazioni di analisi.
